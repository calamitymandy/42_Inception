2 - Anti-cheat checks:

❌ Forbidden:
tail -f
sleep infinity
while true
bash used as main process

“Why is tail -f forbidden?”:

“Because containers must run a real foreground process as PID 1. 
Using tail -f is a hack and breaks proper container lifecycle management.”

4 - PROJECT OVERVIEW QUESTIONS

You WILL be asked this.

❓ How Docker works:

“Docker uses containerization to run applications in isolated environments sharing the host kernel. 
Each container includes everything needed to run a service.”

❓ Docker vs docker-compose:

“Docker runs individual containers, while Docker Compose allows defining and orchestrating multiple services, 
networks, and volumes in a single YAML file.”

❓ Docker vs VM:

“Virtual machines emulate full operating systems and are heavier. 
Docker containers share the host kernel, making them faster and more lightweight.”

❓ Why this structure:

“The structure separates concerns:

srcs/ contains all configuration
requirements/ isolates each service
each service has its own Dockerfile
This improves maintainability and clarity.”

HTTPS (443)	✅ WORK

Check port 443 is open

TLS used	✅ YES
Verify the TLS handshake and confirm that the server is using SSL/TLS correctly:
openssl s_client -connect amdemuyn.42.fr:443


❓ Why only port 443:

“NGINX is the only entrypoint and must enforce secure HTTPS connections using TLS 1.2 or 1.3.”

❓ TLS version:

“Only TLSv1.2 and TLSv1.3 are allowed for security reasons. Older versions are deprecated.”

❓ Where is TLS configured:

“Inside the NGINX configuration file, where SSL certificates and protocols are defined.”
